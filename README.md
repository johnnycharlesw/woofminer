# Woofminer
**Woofminer** is a full-featured database management tool written in PHP. It consists of a single file ready to deploy to the target server.
**Woofminer Editor** offers data manipulation for end-users.

[Official Website](https://www.github.com/johnnycharlesw/woofminer/wiki/)

## Features
- **Supports:** MySQL, MariaDB, PostgreSQL, CockroachDB, SQLite, MS SQL, Oracle
- **Plugins for:** Elasticsearch, SimpleDB, MongoDB, Firebird, ClickHouse, IMAP
- **Requirements:** PHP 5.3+ (compiled file), PHP 7.4+ (source codes)

## Installation
If downloaded from Git then run: `git submodule update --init`

- `woofminer/index.php` - Run development version of Woofminer
- `editor/index.php` - Run development version of Woofminer Editor
- `editor/example.php` - Example customization
- `compile.php` - Create a single file version
- `lang.php` - Update translations
- `tests/*.html` - Katalon Recorder test suites

## Plugins
There are several plugins distributed with Woofminer, as well as many user-contributed plugins listed on the [Woofminer Plugins page](https://www.github.com/johnnycharlesw/woofminer/wiki/plugins/).
