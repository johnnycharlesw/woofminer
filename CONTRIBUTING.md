- Reproducible [bug reports](https://github.com/johnnycharlesw/woofminer/issues/new?template=bug_report.md) are warmly welcomed.
- [Feature requests](https://github.com/johnnycharlesw/woofminer/issues/new?template=BLANK_ISSUE) are also fine, but I'm quite picky about what to accept into Woofminer. Please don't be offended if I close the issue as "Not Planned," especially if it can be achieved with a plugin.
- [Pull requests](https://github.com/johnnycharlesw/woofminer/pulls) for both bug fixes and simple features are welcome. Before working on anything more complicated, get familiar with the [Woofminer philosophy](https://github.com/johnnycharlesw/woofminer/blob/master/developing.md).
